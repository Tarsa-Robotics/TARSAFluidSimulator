01
Hose cross-sectional area
A = (π / 4) · ID²
02
Hose velocity
vhose = Q / A
03
Reynolds number
Re = ρ · vhose · ID / μ
04
Darcy friction factor
Re < 2300 (laminar):   f = 64 / Re
Re ≥ 2300 (turbulent, Colebrook–White):
1 / √f = −2 · log₁₀( ε / (3.7·ID) + 2.51 / (Re·√f) )

Colebrook–White is implicit in f — solved numerically (bisection, replacing what scipy.optimize.brentq does in the Python reference). The Swamee–Jain explicit formula below is used only to bracket the initial guess, never as the final answer:
f₀ = 0.25 / [ log₁₀( ε / (3.7·ID) + 5.74 / Re⁰⁵&sup9; ) ]²

05
Friction pressure loss (Darcy–Weisbach)
ΔPfriction = f · (L / ID) · (ρ · vhose² / 2)
06
Elevation pressure loss
ΔPelevation = ρ · g · H
07
Effective pressure at the nozzle
ΔPeffective = ΔPrated − ΔPfriction − ΔPelevation

Flagged infeasible when ΔPeffective ≤ 0 — the pump cannot overcome the losses at all.

08
Nozzle exit velocity (Torricelli / orifice equation)
vexit = Cv · √(2 · ΔPeffective / ρ)
09
Jet reaction force (momentum flux)
Fjet = ρ · Q · vexit

The "structural reference" value uses the same formula with vexit evaluated at 2·ΔPrated (safety factor 2 on the rated pressure, not on ΔPeffective) — the worst-case number the hardware must survive, not the operating value.

10
Burst margin
burst margin = Pburst / ΔPrated

Flagged red if below the team's SF = 2 convention.

11
Hose mass
hose mass = w · H

w is a direct datasheet value, never computed from ID/OD/material density — real hose weight includes braid/reinforcement mass a wall-volume calculation would miss. Uses H (climb height), not L: the hose hangs straight from a ground-based reel up to the robot, so only the suspended, vertical portion loads the cables — any slack beyond H sits coiled at the base and isn't part of the carried load.

12
Water mass inside the hose
water mass = ρ · A · H

Same H-not-L reasoning as hose mass above. Kept separate from hose mass on purpose — "total suspended mass" below is the sum of both, relevant for what the robot's cable actually has to carry.

13
Total suspended mass
total = hose mass + water mass
14
Hydraulic power
Phyd = Q · ΔPrated

Fluid power the pump must deliver at its rated pressure and flow, shown in the stat card as both watts and horsepower. This is not shaft/motor power — a real drive motor needs more than this to cover the pump's mechanical and volumetric losses, which aren't modeled here. Other pump-spec numbers like RPM, displacement, or the motor's own rated HP don't enter any formula on this page: they determine Q (which you enter directly) but don't change the downstream hydraulics once Q and ΔPrated are known.

15
Water viscosity vs. temperature
μ(T) — linear interpolation over reference values at 0, 10, 20, 30, 40 °C

Standard CRC reference data, not a fitted curve.

16
Solve mode — 1 target

When you lock one output as the target, the one unlocked input is varied by the same bisection root-finder until the target metric above matches what you typed — i.e. it numerically inverts steps 01–14 rather than using a separate formula.

17
Solve mode — 2 simultaneous targets

With 2 inputs unlocked and 2 outputs locked, this becomes a 2×2 nonlinear system (2 unknowns, 2 equations). Rather than a multi-dimensional Newton solve, it's nested bisection: one variable is bisected on the outside; for each candidate value, the other variable is solved exactly (the same 1-target method above) to hit its own target; the outer bisection then drives its own target to zero too. Not every combination of 2 unlocked inputs and 2 target outputs has a solution — e.g. burst margin depends only on pump rated ΔP among the 5 lockable inputs, so targeting it while that input stays locked is genuinely infeasible, not a solver bug.

18
Stage 7 — local impact pressure at glass
Plocal = Fjet / Afootprint(s, θ)

Standoff and spray angle both do the same job — spreading the jet's momentum over a bigger footprint before it hits the glass — via two independent, quantifiable mechanisms. Whichever predicts the larger footprint (smaller pressure) wins:

Afootprint,geometric = π·(rnozzle + s·tan(θ/2))²  [cone/round]
Afootprint,geometric = (bnozzle + 2·s·tan(θ/2))·Lstrip  [flat fan]

θ is the nozzle's full included spray angle. The cone/fan is not born from a mathematical point — a real nozzle exit has finite size, rnozzle (cone) or bnozzle (fan slot width), taken from continuity (Anozzle = Q/vexit, real geometry, not a tunable). A point-origin model breaks down at small standoff: as s → 0 it predicts a footprint smaller than the nozzle's own exit (fgeometric = Anozzle/Afootprint > 1), which is physically impossible — the footprint can never shrink below the exit producing it, no matter how close you get. At large standoff the nozzle-size term is negligible and the formulas reduce to the point-origin shape: a cone footprint's area grows as s², so Plocal decays as 1/s²; a fan footprint's width grows as s but the impact-strip length Lstrip stays roughly constant, so its area grows only ~linearly and Plocal decays as 1/s — the real physical reason a fan (curtain) nozzle holds pressure over distance better than a cone, not just a coincidence of motion path.

Afootprint,turbulent = π·s² / (4·6.2²)  [cone/round]
Afootprint,turbulent = (s / 5.76)·Lstrip  [flat fan]

The geometric formula alone predicts a zero-area (infinite-pressure) footprint at θ = 0, which is unphysical — a "pencil" jet still spreads via turbulent entrainment even with no designed spray angle. This second formula is the equivalent footprint from classical free-jet centerline decay (Rajaratnam): round jets uc/u0 = 6.2·D/s, flat jets uc/u0 = 2.4·√(b/s). Since momentum flux (ρ·u²·A) is conserved along a free jet, the equivalent area is A0 / (uc/u0)² — and because A0 is defined by the orifice itself (π·D²/4 for round, b·Lstrip for fan), the orifice size cancels out algebraically, leaving a floor that depends only on standoff. This floor is what governs near θ = 0; the geometric term takes over and dominates once θ exceeds roughly 15° at typical operating standoffs (200mm+), matching the "DS Twist" nozzle's usable range.

19
Stage 8 — cleaning verdict
R = Plocal / Pthreshold

R ≥ 2 → 🟢 Green (good clean). 1 ≤ R < 2 → 🟡 Yellow (marginal). R < 1 → 🔴 Red (fails — no amount of dwell time fixes it). Pthreshold is a user-adjustable slider from 8 bar (Kim et al.'s proven floor) to 150 bar (industry "glass ceiling," unvalidated for TARSA's actual grime); it defaults to 8 bar until a physical grime test is done.

01
Turns per layer
n = floor(W / d)

Only whole turns count; leftover length at the flange holds no cable.

02
Drum capacity
C = Σk=0…N−1 n · 2π(r + d/2 + k·d) = 2π · n · N · (r + N·d/2)

Each turn is measured along the cable's centerline. Layer k sits k·d further out than the first.

03
Length locked → solve radius
r = L / (2π · n · N) − N·d/2

Infeasible if r ≤ 0: the drum is too long, or has too many layers, for this much cable.

04
Radius locked → solve length
n = ceil(L / (2π · N · (r + N·d/2))),   W = n · d
05
Both locked → solve cable length
L = C

Outer radius r + N·d is where the top layer ends. A real flange needs clearance above that.

06
Zoltan's checkbox — diameter = length
2r = W = n·d  ⇒  C = π · N · d · n · (n + N)

n is the smallest whole number of turns with C ≥ L; both r and W follow from it.
